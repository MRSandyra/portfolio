## 📂 Featured Projects (5)

### 1. Flight Data Analysis (US Delays) ✈️
- **Description:** Exploratory analysis of US flight delay datasets. Identified seasonal patterns, most punctual airlines, and problematic routes.
- **Tech stack:** Pandas, Matplotlib, Seaborn, Jupyter Notebook.
- **Outcome:** Top 3 airlines with best on‑time performance and travel schedule recommendations.

### 2. Global Income Inequality 🌍
- **Description:** A study of income inequality across countries over the last 20 years using World Bank data.
- **Tech stack:** Plotly, NumPy, Scikit‑learn (clustering).
- **Outcome:** Interactive heatmaps and country clusters based on Gini index & GDP per capita.

### 3. Customer Churn Prediction 📉
- **Description:** Built a classification model to predict customer churn for a telecom company.
- **Tech stack:** XGBoost, Random Forest, SHAP, Streamlit (lightweight demo).
- **Outcome:** 89% accuracy with churn class recall of 0.82. Deployed as a mini web app.

### 4. Stock Analyzer – Personal Stock Analysis Tool 📊
- **Description:** An automated stock analysis tool for IDX equities that combines news sentiment (TextBlob + Selenium), fundamental analysis (PER, PBV, ROE, DER), and technical indicators (MA, RSI, MACD, support/resistance) to generate data‑driven investment recommendations (Strong Buy to Strong Sell).
- **Tech stack:** Python, Selenium, TextBlob, yfinance, Pandas, NumPy.
- **Outcome:** Weighted composite scores with JSON reporting. The tool produces clear signals (e.g., “✅ BUY”) and includes a configurable scoring methodology.

### 5. Capstone Project – Flight Ticket Sales Analysis ✈️📈
- **Description:** An end‑to‑end analysis of flight ticket sales data (price, airline, route, stopover, arrival date). Performed data cleaning, feature engineering (total tickets sold per airline), and exploratory data analysis to uncover sales patterns.
- **Tech stack:** Pandas, NumPy, Matplotlib, Seaborn, Google Colab.
- **Outcome:** Identified top 10 airlines by ticket sales, distribution trends, and correlation heatmaps. Cleaned dataset saved as `df2.csv` for further use.
