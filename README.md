## 📂 Featured Projects

### 1. Flight Data Analysis ✈️
- **Description:** Exploratory analysis of US flight delay datasets. Identified seasonal patterns, most punctual airlines, and problematic routes.
- **Tech stack:** Pandas, Matplotlib, Seaborn, Jupyter Notebook.
- **Outcome:** Top 3 airlines with best on‑time performance and travel schedule recommendations.

### 2. Global Income Inequality 🌍
- **Description:** A study of income inequality across countries over the last 20 years using World Bank data.
- **Tech stack:** Plotly, NumPy, Scikit‑learn (clustering).
- **Outcome:** Interactive heatmaps and country clusters based on Gini index & GDP per capita.

### 3. Customer Churn Prediction 📉
- **Description:** Built a classification model to predict customer churn for a telecom company.
- **Tech stack:** XGBoost, Random Forest, SHAP, Streamlit (lightweight demo).
- **Outcome:** 89% accuracy with churn class recall of 0.82. Deployed as a mini web app.
